3D порт MiniCraft 0.6.4.2  на   телефоны с поддержкой  файл для скачивания (MiniCraft 0642.jar)
.jar ## ✨ Возможности версии v1.0
* **Живой 3D-мир и мобы:** курицы, свиньи и овечки днём, а также зомби ночью (с единым Z-буфером глубины и звуками).
* **Меню настроек:**
  * Выбор языка: **Русский / English**
  * Режим камеры: **1-е, 2-е и 3-е лицо** (с 3D-моделью игрока)
  * Ползунки **Чувствительности** и **Дальности обзора**
  * Переключатель времени суток (**День / Ночь**)
  * Переключатель **Сенсорного управления (`ВКЛ / ВЫКЛ`)** — удобно как для сенсорных телефонов, так и для классических кнопочных экранов
* **Аппаратные звуки Java ME (`Manager.playTone`)** и поддержка любых экранов (`MIDP 2.0 / CLDC 1.1`).
