  
## 📱 Версия для кнопочных и сенсорных телефонов с поддержкой .jar (Java ME / J2ME)

Полноценный 3D-порт **MiniCraft 0.6.42** для классических кнопочных и сенсорных  телефонов **Nokia (Series 40 / Symbian)**, устройств с поддержкой **MIDP 2.0 / CLDC 1.1**, а также эмулятора **J2ME Loader** на Android.

* **Файл для загрузки:** [`MiniCraft0642.jar`](./MiniCraft0642.jar)
* **Платформа:** Java ME (MIDP 2.0, CLDC 1.1)
* **Рекомендуемое разрешение экрана:** `240x320` (и любые другие экраны J2ME)

### 🎮 Управление на кнопках Nokia
* **`2` / `4` / `6` / `8`** — движение вперёд, влево, вправо, назад
* **Джойстик (влево / вправо / вверх / вниз)** или **`1` / `3`** — поворот камеры и обзор
* **`7`** — прыжок
* **`5` (Центр джойстика)** — сломать выбранный блок
* **`0` или `#`** — поставить блок
* **`*`** — переключить тип блока (`Grass`, `Dirt`, `Stone`, `Wood`, `Planks`, `Gold`, `Diamond`)
* **`9`** — переключить День / Ночь оригинальная веб версия для современных телефонов и пк - https://github.com/olegvideo-player/Minicraft0642
